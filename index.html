User Data Deletion

This page explains how users can request deletion of their data associated with Word Hunter Pro.

Delete Saved Game Progress

Word Hunter Pro currently saves the player's current level in browser local storage.

To delete saved progress, clear the browser's stored site data for the game.

The saved level will be reset on that browser and device.

Request Personal Data Deletion

If you want to request deletion of personal data associated with Word Hunter Pro, contact the game developer using the email address below.

  1. Write an email with the subject: Word Hunter Pro - Data Deletion Request.
  2. Include your in-game identifier, if available.
  3. Describe the data you want deleted.

Do not send passwords or sensitive account credentials.

What Happens After Your Request?

The developer will review your request and may ask for reasonable information to identify the relevant data.

Personal data controlled by the developer that is not required to be retained by law will be deleted.

This webpage does not automatically process deletion requests.

Facebook / Meta Data

If you accessed Word Hunter Pro through Facebook, you can review or remove the app through your Facebook settings under Apps and Websites.

Removing the Facebook app does not automatically clear browser-local game progress.
